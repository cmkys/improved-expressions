Card: —
Sprites for this card live in /characters/<card>/<character>/ inside your user data folder. Two ways to give an expression multiple images, freely combined: suffix files (casual.png, casual-1.png → casual) and expression folders (every image inside counts, any filename). Expression folders and groups are stored as companion folders next to the character folder, e.g. <character>.jumping/ — SillyTavern's sprites API can't read deeper nesting. Drop a whole folder onto a character to upload & register it in one step; folders made on disk are added with the button, then Scan picks up changes. Use the on an expression to describe its setting/outfit — the description is sent to the classifier for accuracy.
